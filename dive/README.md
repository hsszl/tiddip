# 兔潜奇境 · 视频对照复刻

按用户提供的长视频对照制作：点击上浮，管道完全移出左边界后计分，碰到管道或上下边界结束。角色、海底、文字和按钮均为矢量绘制，不使用截图贴图或 SVG 内嵌位图；测量依据见 `REFERENCE.md`。不依赖外部字体、框架或服务端。

- 打开 `index.html` 即可玩；点击 / 空格 / ↑ / W 上浮，P / Esc 暂停，Enter 重开。
- 212:520 胶囊圆框、黑色内沿和白色外圈，等比撑满可用高度；开始按钮在支持的浏览器中请求原生全屏，右下角可切换。逻辑尺寸固定，窗口大小不改变速度或管道间距。
- 切到后台自动暂停；最高分和声音开关保存在浏览器本地，存储被禁用也可玩。声音默认关闭。
- 运行文件：五个 HTML/CSS/JS、`assets/` 中三个 SVG 及 `.htaccess`。`tests/` 和说明文档不上传。
- 菜单恢复宋体标题、TAP 提示及底部播放按钮；结束画面使用固定 SVG 字形，避免手机字体替换。海底以管道半速滚动，背景/前景分别缓存并平铺，不每帧重算光效。
- 必要规则与输入检查：`node --test dive/tests/game.test.cjs dive/tests/input.test.cjs`。
