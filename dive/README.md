# 兔潜奇境 · 视频对照复刻

按用户提供的长视频对照制作：点击上浮，管道完全移出左边界后计分，碰到管道或上下边界结束。角色、海底、文字和按钮均为矢量绘制，不使用截图贴图或 SVG 内嵌位图；测量依据见 `REFERENCE.md`。不依赖外部字体、框架或服务端。

- 打开 `index.html` 即可玩；点击 / 空格 / ↑ / W 上浮，P / Esc 暂停，Enter 重开。
- 212×520 画面嵌入 256×564 厚黑框，外有浅色金属圈，整块设备等比撑满可用空间；开始按钮在支持的浏览器中请求原生全屏，右下角可切换。窗口大小不改变游戏速度或管道间距。
- 两种模式均有踢腿恢复期，快速连点不会重置速度或动作；普通模式管道更慢。当前恢复期 300ms、普通模式半速属于待定量校准的实现值，不能当作原程序参数。
- 结算页顶部三点打开关于与设置：原作 1.0.5、NEORUAA / 无源流沙、地狱模式开关；返回保留结算状态，选择影响下一局并保存到本地。
- 切到后台自动暂停；最高分、难度和声音开关保存在浏览器本地，存储被禁用也可玩。声音默认关闭。
- 运行文件：五个 HTML/CSS/JS、`assets/` 中三个 SVG 及 `.htaccess`。`tests/` 和说明文档不上传。
- 菜单保留宋体风格标题；设置页、数字和其他界面字形采用 MiSans Regular / Demibold 轮廓，保持自然宽高比，不依赖手机字体。兔子由参考姿态分色描成矢量轮廓，动作不再只按瞬时速度切图。
- MiSans 来源及许可：`https://hyperos.mi.com/font/zh/download/`。本项目仅包含字形美术路径，不分发或修改字体软件。原作署名来自用户提供的设置页，未获得原作源码。
- 海底按累计行进距离半速滚动，背景/前景分别缓存；切换难度不会挪动已结束画面。
- 必要规则、输入与动作检查：`node --test dive/tests/game.test.cjs dive/tests/input.test.cjs dive/tests/render.test.cjs`。
