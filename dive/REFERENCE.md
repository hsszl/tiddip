# 长视频对照记录

参考：用户提供的 `e17da7af69fe33081290683322e7b11a.mp4`（720×1280、30 fps、48.536 秒）以及三张角色细节截图。截图仅供描形，未作为运行素材。

## 可直接观察的界面

- 2.5–3.6 秒菜单：宋体「兔潜奇境」、居中的潜水兔、两侧粉色 TAP 箭头和白色手势；顶端返回、底部椭圆播放按钮，无菜单管道和模式副标题。
- 游戏中：粉色分数、绿色细管和浅粉管帽；角色大致位于屏幕宽度的 34%，背景随游戏横向滚动。
- 46 秒结束画面：顶部三点，GAME OVER / MAX / (地狱模式)，底部双箭头重试按钮。
- 外形：保持 212:520 的逻辑画面比例，黑色内沿、白色外圈；所有尺寸随画面统一缩放。

## 运动测量与采用值

4–22 秒按视频帧率采样，先定位亮屏左右边界、扣除相机位移，再跟踪管道与头部。中间结果按宽 192 归一化，最后乘 212/192 换算到本项目坐标。

| 项目 | 测量依据 | 实现值 |
| --- | --- | --- |
| 管道速度 | 14 段移动轨迹；中位 210.075 px/s（宽192），换算 231.958 | 232 px/s |
| 管道宽度 | 绿色主体中位31，换算34.23 | 34，管帽两侧各伸出3 |
| 相邻管道 | 连续轨迹周期中位1.1334秒；换算中心距262.90 | 264 |
| 开口 | 绿色上下主体间距换算约142；扣除两端管帽 | 净开口132 |
| 上浮曲线 | 6.4333–6.7333秒头部10点拟合；原归一化加速度1072.1、残差RMS 0.91px | 重力1160，点击速度−330 |
| 下落 | 17.13–17.47秒近似匀速段 | 上限145 px/s |
| 背景 | 18.0–18.5秒同一水泡横移约管道的一半 | 116 px/s |
| 计分时刻 | 视频中管道过兔子后分数仍不变，离开左边界才增加 | 管帽完全退出左边界计分 |

单位均为本项目逻辑像素，随屏幕等比显示。画面有透视、手指遮挡和曝光变化；以上为视频拟合与描形，不是从原程序提取的参数。较差的头部拟合片段没有用作校准依据。

## 字形与素材

- `rabbit.svg`：按参考轮廓手绘路径，收腿、伸腿及上浮三姿态，固定头盔锚点。
- `sea.svg`：矢量水色、柔光、远处水草、气泡和前景珊瑚，背景/前景拆成两行；运行时缓存后平铺。
- `lettering.svg`：标题以 SimSun、英文以 Arial、模式文字以 Microsoft YaHei 的轮廓生成并按视频尺寸排列；标题、结算和数字不依赖客户端字体。
- 三个 SVG 均无 `<image>`、内嵌 PNG/WebP/JPEG 或外部资源。

规则测试覆盖测得的水平位移、开口/间距、上浮轨迹、下落限速、计分时刻与可见管帽边缘；并保留暂停、重置和适配相关检查。
