# tiddip 迷雾棋盘 Demo

Node.js 服务端 + 原生 JS 客户端，无安装依赖。2–6 人，8×8 共享迷雾，支持电脑对手。

## 本机运行

在 PowerShell 中：

```powershell
cd D:\MyProjects\tiddip.com\game
npm start
```

打开 http://127.0.0.1:3000/game/ 。每个独立标签页保存自己的会话。房间存内存，重启服务会清空。

## 当前玩法

- 每回合最多移动一次、攻击一次，顺序自由；道具不限张数，用后弃牌，手牌上限五张。
- 普通移动上下左右一格。疾跑和匕首突进可直线走最多两格；左轮侧步可斜走一格，都占本回合移动且只触发落点。
- 攻击伤害统一为 1，回血不超过武器上限。手枪首次零血急救，最后一名存活者获胜。
- 武器公开，手牌私有；其他人只能看到张数。未揭示地形不会发给客户端。
- 十种武器：狙击枪、步枪、手枪、长弓、回旋镖、匕首、战斧、十字弩、迫击炮、左轮。能力和射程图见武器 ⓘ。
- 八种道具：急救包、护盾、传送、雷达、疾跑、弹药、巧手、拆弹钳。手牌直接显示短效果，悬停看提示，没有 ⓘ。
- 狙击枪仍是 5 血、直线第 2/3 格、同格射击每局一次；弹药不能补充它，也不能换枪绕过已用记录。
- 军械库需站在格子上手动使用，每人每座一次。随机换武器，不回血、不恢复已用能力；其他地形保持入格触发。
- 地雷只能炸到其他已翻开的合法格子；厕所仅容一人。雷达和鹰眼只揭示、不触发地形。

## 界面与邀请

棋盘持续提示普通攻击范围，攻击模式突出目标；技能模式或悬停技能按钮显示能力范围。私有手牌按类别用少量颜色区分。浅色模式使用深色提示浮层，夜间使用接近黑色的中性灰及简化牌背。

所有客户端按服务器事件顺序播放移动、攻击、伤害、能力和道具反馈。移动期间隐藏终点静态棋子，多次移动顺序播放；移动抵达或揭图能力提示后，逐格展示新揭示地形，避免最终地图抢先出现。动画仅影响显示，服务端状态始终有效。射击、投掷和近战有不同反馈。记录以图像表示，点击查看事件当时的信息。每秒同步，远端可能有约一秒延迟；初次加载不重放历史。

“邀请”可复制链接，在支持的浏览器中调用系统分享；是否有微信取决于设备和浏览器，不能强制指定。分享依赖安全上下文及用户点击。链接只含公开房间号，不带会话令牌。收到其他房间链接时先显示加入表单，可返回原对局；对局开始后不接受新玩家。

当前服务监听 `127.0.0.1:3000`，其他电脑和手机打不开这个地址，邀请窗口会提示。未开放公网、局域网监听、防火墙或部署 Supreme。上线可访问的 HTTPS 地址后才能给朋友发送有效联机链接。

官方资料：[Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。本次未接微信专用 SDK，也未实际发送消息给任何人。

## 文件与安全边界

- `rules.js`、`range.js`：共享配置与范围几何。
- `server/`：房间、会话、回合、移动、战斗、能力、地形、道具、机器人和 HTTP。
- `client/`：棋盘、卡牌、属性、邀请、图像记录、移动动画和攻击反馈，按职责分文件。
- `client/assets/`：28 张独立卡牌 SVG，另有牌背与界面图标；`client/artwork.html` 是插画预览页。

服务端决定发牌、位置、血量、次数与胜负，并校验令牌、回合、射程、道具归属和版本；拒绝旧请求重放及伪造状态字段。按连接 IP 每分钟限制创建 10 次、其他写请求 120 次、读取 600 次，不信任客户端转发 IP。代理部署需重新评估限流配置。

没有账号、数据库、跨重启恢复、行动倒计时或自动掉线淘汰。无法阻止一个人多开或自动操作；关闭页面不代表离开，轮到掉线者会等待。正式部署还需 HTTPS、令牌保护和主机运行环境确认。本次未连接 GitHub 自动部署。

公开部署前还需限制每来源的活跃房间数量：现有全局 200 间上限可被匿名创建逐步占满，单纯轮询会刷新房间回收时间。若经反向代理，需确认连接 IP 是否合并，避免所有玩家共用限流桶。当前默认本机监听，没有开放公网。

Spaceship 官方确认 Node.js Selector 使用 Passenger 托管应用。当前房间存于单进程内存，不能直接把整个服务当静态文件上传：先确认应用入口、URL 映射、单进程运行及空闲回收策略，再选择持久化或适合单进程的运行环境。Supreme 是限时试用，非长期免费。

官方资料：[Spaceship Node.js 配置](https://www.spaceship.com/knowledgebase/setup-nodejs-application-spaceship-hosting/)、[Passenger 进程池与空闲回收](https://www.phusionpassenger.com/docs/references/config_reference/apache/)。
