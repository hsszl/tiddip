# tiddip 游戏

Node.js 服务端 + 原生 JS 客户端，无安装依赖。2–6 人，默认 8×8 共享迷雾，支持电脑对手。

## 本机运行

在 PowerShell 中：

```powershell
cd D:\MyProjects\tiddip.com\game
npm start
```

打开 http://127.0.0.1:3000/game/ 。已有标签页保留各自会话；同一浏览器会按房间记住最近使用的身份，新标签页打开该房间链接时恢复。默认房间存内存；设置私有目录 `GAME_DATA_DIR` 后可跨重启恢复。部署入口及配置见 [DEPLOY.md](DEPLOY.md)。

## 当前玩法

- 房主在大厅点击“地图 8×8”，在同一窗口拖动框选或输入宽高，支持 4–16 列、4–16 行的长方形地图。两种输入同步，方向键也可调整，点击应用才保存；开始后锁定尺寸，重开沿用。地形数量按面积缩放，旧存档默认 8×8。
- 每回合 30 秒，超时自动换人；最多移动一次、攻击一次，顺序自由。道具不限张数，用后弃牌，手牌上限五张。
- 普通移动上下左右一格。疾跑和匕首突进可直线走最多两格；左轮侧步可斜走一格，都占本回合移动且只触发落点。
- 攻击伤害统一为 1，回血不超过武器上限。手枪首次零血急救，最后一名存活者获胜。
- 发牌后即公开所有人的武器、血量和上限，包括选出生点阶段；手牌私有，其他人只能看到张数。未揭示地形不会发给客户端。
- 十种武器：狙击枪、步枪、手枪、长弓、回旋镖、匕首、战斧、十字弩、迫击炮、左轮。能力和射程图见武器 ⓘ。
- 八种道具：急救包、护盾、传送、雷达、疾跑、弹药、巧手、拆弹钳。手牌直接显示短效果，悬停看提示，没有 ⓘ。
- 狙击枪仍是 5 血、直线第 2/3 格、同格射击一次；弹药不能补充它，军械库可恢复。
- 军械库需站在格子上手动使用，每人每座一次。随机换武器并恢复技能（含被动和狙击枪记录），不回血、不增加本回合移动或攻击次数；其他地形保持入格触发。
- 地雷只能炸到其他已翻开的合法格子；厕所仅容一人。雷达和鹰眼只揭示、不触发地形。

## 界面与邀请

攻击模式或悬停攻击按钮时显示射程，平时不高亮；技能模式或悬停技能按钮显示能力范围。已使用的动作不再提示范围。回合标题旁显示倒计时，最后五秒变色。私有手牌按类别用少量颜色区分。浅色模式使用深色提示浮层，夜间使用接近黑色的中性灰及简化牌背。

武器卡的心形减号表示伤害；射程图放在悬停提示和详情中，卡面不放射程图。本人回合使用深色倒计时、加粗标题和短暂提示。文案只写动作或状态，不添加搭话和重复解释。界面文案参考 [GOV.UK](https://www.gov.uk/service-manual/design/writing-for-user-interfaces) 的简短、直接原则。

所有客户端按服务器事件顺序播放移动、攻击、伤害、能力和道具反馈。移动期间隐藏终点静态棋子，多次移动顺序播放；移动抵达或揭图能力提示后，逐格展示新揭示地形，避免最终地图抢先出现。动画仅影响显示，服务端状态始终有效。射击、投掷和近战有不同反馈。记录以图像表示，点击查看事件当时的信息。每秒同步，远端可能有约一秒延迟；初次加载不重放历史。

淘汰时棋子消散并留下编号骷髅，复活和胜利显示独立提示；这些事件发送给所有玩家。伤害、治疗、获得手牌有数字反馈，支持系统减少动画设置。淘汰后可继续观战或退出，结算面板也提供退出。退出立即返回首页，同时通知服务器；退出不受回合版本变化影响，服务器确认后撤销令牌。网络中断时只能先退出页面，服务器中的房间仍需等待回收。

“邀请”可复制链接，在支持的浏览器中调用系统分享；是否有微信取决于设备和浏览器，不能强制指定。分享依赖安全上下文及用户点击。链接只含公开房间号，不带会话令牌。打开链接时优先恢复该房间已有身份，否则用上次昵称（没有则用“玩家”）直接加入。失败时显示原因，若原标签页另有会话仍可返回。对局开始后不接受新玩家，但有效会话可以重连。

当前服务监听 `127.0.0.1:3000`，其他电脑和手机打不开这个地址，邀请窗口会提示。未开放公网、局域网监听、防火墙或部署 Supreme。上线可访问的 HTTPS 地址后才能给朋友发送有效联机链接。

官方资料：[Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)。本次未接微信专用 SDK，也未实际发送消息给任何人。

## 文件与安全边界

```text
tiddip.com/
  index.html            网站首页
  favicon.svg           网站图标
  docs/                 原始需求
  game/
    app.cjs             启动入口
    package.json        Node 配置与本地命令
    rules.js, range.js  前后端共享代码
    client/             网页、样式和 SVG
    server/             服务端逻辑
    docs/               游戏说明、设计和部署文档
    tests/              客户端与服务端测试
    scripts/            本地打包工具
    deploy/             容器配置
    dist/               生成的上传包，不进 Git
    .data/              本地私有存档，不上传、不进 Git
```

在 `game` 目录运行 `npm start` 启动，`npm test` 检查，`npm run pack` 生成 `dist/tiddip-game.zip`。手动部署只需这个 ZIP；网站首页和图标仍单独放在网站文档根目录。游戏包放入 Node 应用的 Application root，两者用途不同。

- `rules.js`、`range.js`：共享配置与范围几何。
- `server/`：房间、会话、回合、移动、战斗、能力、地形、道具、机器人和 HTTP。
- `client/`：棋盘、卡牌、属性、邀请、图像记录、移动动画和攻击反馈，按职责分文件。
- `client/assets/`：28 张独立卡牌 SVG，另有牌背与界面图标；`client/artwork.html` 是插画预览页。

服务端决定发牌、位置、血量、次数、截止时间与胜负，校验令牌、回合、射程、道具归属和版本；拒绝旧请求重放及伪造状态字段。创建每分钟 10 次，其他写请求 120 次，读取 600 次；已认证玩家的读写额度独立。匿名来源按 IPv4 地址或 IPv6 /64 计，不信任未配置代理的转发头。

每来源最多保留三间房，全局 200 间；空房立即回收，只读轮询不续期。大厅/选出生点/游戏/结束的无人工操作回收时间分别为 15/10/30/10 分钟，绝对寿命六小时。超时由后台和请求入口共同执行；地雷待选落点会自动选择合法已揭示格，无落点则留在原格。

持久化为单进程私有 JSON 文件和进程锁，不是分布式数据库。没有账号认证，不能防多开、串通、自动操作或分布式占房。当前没有公网部署、GitHub 自动部署；上线仍需 HTTPS、单实例及主机运行限制确认。Supreme 是限时试用，非长期免费，具体步骤和代理配置见 DEPLOY.md。

身份由服务器生成的随机会话令牌识别，不依赖昵称或客户端提交的玩家 ID。昵称只在加入房间时设置，回合命令不允许改名；修改页面文字不会改变服务端。不能通过改名或指定别人的 ID 操作对方；获得别人的令牌则可以冒充该会话，因此公网必须使用 HTTPS。标签页会话存储保留当前玩家，本地存储按房间记住最近使用的令牌；已有标签页优先自己的身份，新标签页可恢复。退出撤销该令牌，共用它的其他标签页也会失效。不同浏览器或无痕窗口不共享身份。这不验证真人身份，也不阻止多开；清理浏览器存储会丢失恢复身份。

官方资料：[Spaceship Node.js 配置](https://www.spaceship.com/knowledgebase/setup-nodejs-application-spaceship-hosting/)、[Passenger 进程池与空闲回收](https://www.phusionpassenger.com/docs/references/config_reference/apache/)。
