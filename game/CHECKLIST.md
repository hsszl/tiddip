# 规则记录

## 用户已确认

- [x] 每回合移动、攻击各最多一次，可跳过、顺序自由。
- [x] 一次移动上下左右一格。
- [x] 地图揭示所有人共享；出生、进入都翻开，因此没有迷雾中的玩家。
- [x] 狙击枪只打直线第 2、3 格，同格技能每局一次；所有武器伤害 1。
- [x] 零血先判断保命技能，没有就淘汰；最后一名存活者获胜。
- [x] 地雷落点由被炸玩家选择，只能落到其他已翻开的合法格子。
- [x] 血量不能超过武器上限；自己的回合可以连续使用持有的道具，不限次数。
- [x] 服务端、客户端分开；首版直接做真实多人。
- [x] 地图每块是图片，暂时用黑紫占位图；地图放大、界面简洁。
