# 界面文案约定

这次的问题不只是某几个词：“把规则定下来”把本来简单的按钮写成了主持人讲话，“界面研究”和英文小标题占着位置却不帮助玩游戏。以后按下面的标准检查。

1. 按钮直接写操作：创建房间、加入、移动、攻击、结束回合。
2. 状态只说当前发生了什么：轮到你了、等待其他人选出生点。
3. 提示说清下一步；错误说清为什么做不了。不要加鼓励、承诺或感叹号。
4. 不写口号、假设玩家心情的句子、没有用的英文标题、排比和故作深刻的总结。
5. 不在玩家界面介绍模块、架构或“体验”。必要的 Demo 限制集中放规则说明。
6. 有不确定的规则，写进文档，明确是临时配置；不要在游戏里堆问卷。

| 旧文案 | 替换 |
| --- | --- |
| 把规则定下来。 | 规则 |
| BEFORE WE PLAY | 删除 |
| 今天开始您的新旅程 | 删除 |
| 行动意图已成功提交 | 已移动 / 已攻击，或直接更新地图 |
| 开启迷雾探索之旅 | 开始 |

检查方法：读出声。如果像广告、主持词或产品汇报，就改成玩家此刻需要知道的一句话；没有信息就删掉。
