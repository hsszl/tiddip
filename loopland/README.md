# Loopland

从 `D:\TEMP\loopland` 提取的同屏双人版本，原项目不变。没有 AI、训练、模型或联网功能。

直接打开 `index.html` 即可玩，不需要 Node.js、本地服务器或安装依赖。

- 蓝方：WASD；粉方：方向键。
- 空格暂停，Enter 开始。离开标签页自动暂停。
- 设置中调速：1–25 格/秒，默认 8；立即生效，重开时保留当前速度。打开设置会暂停，关闭后点“继续”。
- 80 × 80 棋盘；每局 3 分钟游戏时间（1440 步）。和原版一致，变速也会同步改变倒计时速度。
- 绕一圈回到自己的领地即可占地，碰到线会重生，已有领地保留。
- 先占满 50% 获胜，时间到后比较领地。

## 文件

| 文件 | 用途 |
| --- | --- |
| index.html | 页面 |
| style.css | 排版与主题颜色 |
| game.js | 移动、圈地、碰撞、重生与胜负 |
| render.js | Canvas 绘制 |
| app.js | 键盘、计时、暂停与界面更新 |
| theme.js | 独立亮暗切换 |
| tests/ | 必要规则检查，不上传到网站 |

已部署：[https://tiddip.com/loopland/](https://tiddip.com/loopland/)。同屏双人，游戏逻辑仍全部在浏览器运行，不是两台设备联网对战。

线上目录为网站文档根目录下的 `loopland/`，只含上表六个运行文件。不需要 Node.js application，也不影响 `/gaogame/`。更新时覆盖这六个文件即可；GitHub push 目前不会自动发布。
