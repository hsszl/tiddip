# 手机筛选

直接打开 `index.html`；不需要安装依赖、构建或启动服务器。只在此目录新增文件，未修改首页或其他项目，也未发布线上。

## 页面

- 所有品牌混排，品牌可多选；搜索型号、芯片和原始参数文字。
- 默认显示价格、GB6 多核、重量、电池、屏幕、有线充电 6 组双端滑块；“更多参数”展开其余控件。
- 共 23 个数值范围：价格、GB6 单/多核、GB7 单/多核、安兔兔、重量、厚度、屏幕尺寸/刷新率、电池、有线/无线功率、内存/存储、主摄/长焦/超广角/前摄像素、持续/瞬时触控、蓝牙版本、CPU 最高频率。
- 8 个分类条件：芯片、分辨率、屏幕形态、防护、内存类型、闪存类型、USB、发布年份。数值字段均支持排序，另有名称和发布时间排序。
- 横条只显示最近价格；GB6 单/多核分数紧接芯片名称，屏幕英寸与“小屏 / 中屏 / 大屏”默认直接可见。点击展开其他参数，不展示上期价或价格历史。
- 本页尺寸分档采用屏幕对角线：小屏 ≤ 6.4 英寸，中屏 > 6.4 且 < 6.7 英寸，大屏 ≥ 6.7 英寸；这是本页显示规则，不是行业标准。折叠机的内外屏分别标注，默认屏幕滑块下也直接显示分档刻度。

参数采用该页公开嵌入的 `PHONES` JSON，日期来自 `DATES` 和页脚；保留全部原始记录和字段。当前快照为 160 款、12 个品牌，原站标注更新至 **2026-11-11**。`data.js` 内记录采集时间、来源及源页面 SHA-256。缩略图直接引用原站公开图片；断网或图片失败时显示品牌首字，不阻断筛选。

源站当前未提供的宽度、系统、SIM、二手等数据不猜填，不建立虚假的筛选项；非空原始备注可以通过搜索和详情查看。原站数据和图片不因本项目独立编写而取得新的授权，本次仅制作本地版本，未部署或推送。

## 数据规则

- 价格、运行内存、存储必须由**同一配置**同时满足；筛选后横条只显示符合的配置，价格排序也基于这些配置。
- 价格按每个配置最新记录显示，保留批次日期；该期缺失或无货不回填为旧价。历史数据仅保存在原始快照中，不显示为额外价格栏目。
- 缺失不是 0：未启用的范围不排除缺失；启用范围后只留下有明确数据且匹配的机型。正序、倒序都将缺失排序值放末尾。
- 重量、厚度按原文中的单位解析，并采用最重/最厚值；原文完整保留。折叠机的闭合厚度可能混在原站重量字段中，联合解析两字段的 `g` 和 `mm`，避免串单位或只使用展开厚度。
- GB6 / GB7 分开；安兔兔保持原表数值，原表没给版本，不做跨平台或跨版本综合评分。
- 无线功率、摄像头、USB 等仅从明确标注解析；未提到无线充电不推断为不支持。复杂原文不确定时保留原文、数值留空。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html`、`style.css` | 极简筛选栏和横条布局 |
| `app.js` | 双端滑块、品牌、排序、详情及 DOM 渲染 |
| `model.js` | 单位解析、配置报价、筛选与排序，无 DOM 依赖 |
| `data.js` | 可离线加载的真实数据快照，不执行上游 JavaScript |
| `scripts/update_data.py` | 手动刷新快照，标准库实现 |
| `tests/` | Node 原生测试、Python 单元测试 |

`index.html` 的样式和界面脚本 URL 带内容哈希。修改这些文件后同步更新哈希，避免桌面预览只刷新 HTML、仍执行缓存的旧脚本；发布前读回预览中的实际横条确认。

## 手动更新

在仓库根目录执行：

```bash
python -B phones/scripts/update_data.py
```

若普通 HTTP 访问失败，可在浏览器保存原站 HTML 后：

```bash
python -B phones/scripts/update_data.py --source-html "保存的原站.html"
```

更新器只读取 JSON 常量，不执行网页脚本；空数据、重复 ID 或缺少标记会报错，旧快照保持不变。没有设置定时任务。
